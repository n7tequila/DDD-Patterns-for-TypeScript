1. **审查异味的严重级别与强规则映射对齐**：编号规则至少 HIGH；第 5、10、11、12、13 条涉及用户数据或跨信任边界时为 CRITICAL。

3. **报告模板多一个 Rule 字段**，引用强规则编号或异味名。
4. **评测题材用会议室预订与图书馆借阅**，与示例工程同领域或相近，与儿童学习项目无关。
5. **评测运行产物不进 git**（`evals/runs/` 已忽略），只提交结果汇总。
